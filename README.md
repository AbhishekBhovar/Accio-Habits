# HP Fitness RPG — HP52 Campaign Build

Major prototype upgrade for Books 1–2:
- Journey repurposed to **Campaign**: seven-year road toward the final battle, with only battle-relevant encounters shown.
- **Read / Study** added as a daily Knowledge habit.
- Readiness pillars now show their real-world training sources.
- Battle tab now opens with a live **Next Battle** forecast: XP remaining, readiness gaps, and best training focus.
- Existing save key is preserved so current progress remains compatible.
